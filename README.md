## New: WhatsApp bot starter
I added a minimal WhatsApp bot starter in [`whatsapp_bot/`](whatsapp_bot) using FastAPI + WhatsApp Cloud API.

Quick start:
1. `cd whatsapp_bot`
2. `cp .env.example .env` and add your Meta credentials
3. `pip install -r requirements.txt`
4. `uvicorn main:app --reload --host 0.0.0.0 --port 8000`

See full setup details in `whatsapp_bot/README.md`.
